# python-todo-cli
Консольный менеджер задач (To-Do List) на Python с использованием ООП и сохранением данных в JSON

## Функционал
* **Просмотр задач:** Отображение нумерованного списка всех текущих задач со статусом выполнения (`[x]` — выполнено, `[ ]` — в процессе).
* **Добавление задач:** Быстрое создание новых записей через консольный ввод.
* **Отметка о выполнении:** Изменение статуса выбранной задачи по её номеру.
* **Удаление задач:** Удаление неактуальных задач из списка с защитой от ввода некорректного номера.
* **Автосохранение:** Автоматическая синхронизация всех изменений с файлом `tasks.json`.

## Архитектура проекта
Код разделен на логические компоненты с помощью классов:
* **`Task`** — класс отдельной задачи. Отвечает за хранение названия, статуса выполнения и конвертацию объекта в словарь (`to_dict`) для последующей сериализации в JSON.
* **`TodoList`** — класс-менеджер. Управляет списком объектов `Task`, отвечает за добавление, удаление, изменение статуса, а также чтение и запись файла `tasks.json`.

## Стек технологий
* **Язык:** Python 3
* **Стандартные библиотеки:** `json` (сериализация данных), `os` (проверка существования файла в файловой системе)
